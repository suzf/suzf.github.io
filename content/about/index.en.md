## Jeffrey Su

DevOps Engineer focused on infrastructure automation and cloud-native operations. This blog documents real-world practices and lessons learned.

### What I write about

- **Infrastructure as code** — Terraform state management and multi-cloud setups.
- **HashiCorp operations** — upgrading Consul and Nomad server clusters.
- **Containers** — Dockerfile best practices and the pitfalls that show up in production.
- **AI tooling** — installing OpenClaw and the skills worth adding to it.
- **Developer fundamentals** — Base64, UUIDs, regular expressions, TLS certificate chains and Unix timestamps.

### Tools

I also build [Suzf](https://suzf.net/en/tools), a set of free developer tools that run in your browser: JSON formatter, Base64 and URL codecs, regex tester, SSL checker and more. Many posts here link to the tool they cover.
